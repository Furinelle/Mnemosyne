     on repeated backfill, with all six JSON counters zero.

     Body/config CAS rejects writes. Same-size local asset replacement changes

     JSON backfill gives invalid=2 for malformed responses, failed=2 for HTTP 503,

Implementation/diagnostics:
- backfill_stats returns computed/written/skipped_stale/invalid/repaired/failed.
  computed counts vectors returned by compute; invalid provider responses rejected
  before returning vectors are counted as invalid, not computed.
- Query inference and cache selection use the same ModelProfile. Post-inference
  settings and local asset hashes are rechecked; profile changes discard vectors.
- diagnose is read-only, never infers/downloads; statuses are disabled,
  missing_assets, incompatible, corrupt, stale, ready.
- Explicit embedding revision participates in fingerprint. Remote providers can
  silently change same-name alias weights; that cannot be discovered locally.
- Real ONNX inference and real remote service quality are NOT validated. ONNX
  asset-change tests use inert bytes with injected fake inference. Whole-database
  corruption degrades search safely; automatic destructive DB rebuild is not added.
